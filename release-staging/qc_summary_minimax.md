## 语速：试测后一次全局定档

MiniMax 的 speed 语义与 edge rate 不同，先试合成 3 段（S0a 导览 / S1_2 新闻 / S3e 数据）量净语速：

- speed=1.0 试测：S0a 298.9 / S1_2 315.8 / S3e 293.6，合计 **300.8 字/分**（与 EP001 数据反推的 ~295 互证）——低于目标带 330–360。
- 按任务口径只整体调一次：目标带中点 ~345，speed 定为 **1.15** 全段统一。
- 成片实测：**净语速 345.5 字/分**（3,677 字 / 净发声 638.6s），落在带内；含停顿 **331.0 字/分**；总时长 **666.6s（11:07）**。
- 本版未向云健提速版的 366 强行对齐——语速本身就是本试听版的对比维度之一，只要求进带。
