2026-11-03。所有者要求：用 MiniMax 音色再录一版对比，**不要情绪**。第一版 MiniMax（ep001.mp3）有三段被标了 emotion（S0a happy、S3c surprised、S3g happy），本版把这个变数去掉：MiniMax `speech-2.8-hd`＋温润男声 `Chinese (Mandarin)_Gentleman`，**全部 17 段 emotion 一律 null**，与云健提速版同稿、同语速档、同停顿口径对照。纯人声、无前导音、无乐床。成片 `ep001_minimax_flat.mp3`，**仅供试听对比，未发布、未进 feed**。

## 三查与文本改动（合成前）

底本 = 定稿 `spec_ep001.json` 的 reading，display 一字未动。落实两处已定修正（与云健提速版一致）：

- S0b 结尾：「先来快速看一下昨天的赛果。」（不用「过一遍」）
- S1_1 结尾：「把这份悬念，带进了巴黎。」（把字句宾语与「带进」之间加逗号断开）

多音字定音：沿用定稿的 pronunciation_dict 拼音钉（21 条），本版新增 7 条（MiniMax 带调拼音口径，共 28 条）：重新 (chong2 xin1)、重量 (zhong4 liang4)、冠军 (guan4 jun1)、长路 (chang2 lu4)、都得 (dou1 dei3)、够得上 (gou4 de2 shang4)、还 (hai2)。长句断点：全稿扫描无超过 25 字无标点连续段，不另加断点。重音：靠既有句式与标点（结论先行、编号三点），未改写句子。

## 质检（faster-whisper 逐段回听拼音比对＋数字专项）

方法：whisper medium int8、beam 5＋VAD（与前几轮同一口径；faster-whisper 1.2.1 / ctranslate2 4.8.4 / pypinyin 0.55.0 版本对齐），按组装报告的段时间轴从成片切片逐段比对。

执行说明（如实记录）：本机当时被 Carbon League 训练任务与云健提速版 QC 挤满（4 核、负载一度 15+），本地两轮 QC 都被拖到每段数分钟且无法收尾；最终把同一脚本、同一参数搬到 GitHub runner 上跑完（run 41563349413）。本地已完成的前 9 段 ratio 与 runner 结果**逐段一字不差**（如 S0a 0.968、S1_1 0.816），两地互证，数值可信。另注：本地日志只打印 ASR 前 160 字，中途一度误判为「ASR 丢尾段」，后以 runner 产出的完整 JSON 文本证伪——成片与转写均完整，误判源于日志截断显示。

逐段拼音 ratio：S0a 0.968 / S0b 0.920 / S1_1 0.816 / S1_2 0.923 / S1_3 0.843 / S1_4 0.899 / S1_5 0.885 / S2 0.878 / S3a 0.937 / S3b 0.932 / S3c 1.000 / S3d 0.982 / S3e 0.952 / S3f 0.860 / S3g 0.923 / S4a 0.947 / S4b 1.000。

**结论：17 段全部核完，零确认合成读错，无需重合成任何段。** 低 ratio 段逐段拆解后，失分全部来自三类 ASR 侧伪影，无一处是 MiniMax 读错：

1. **阿拉伯数字写法**（最大头）：ASR 把「六比一」写成「6比1」、「九千五百五十」写成「9550」，与目标的逐字拼音对不上而整块计损。数字密集的新闻段（S1_1–S1_5）与积分段（S2/S3f）因此系统性偏低，但**数值逐个核对全部正确**：五场决赛比分、抢七小分（7-4 / 7-1 / 7-3 / 11-9）、积分链 9550 / 9450 / 9350 / 7950 / 5110 / 差 4240 / 都灵线 3194 / 3170 / 差 24 / 德约 2900 / 落后 294，ASR 均原样复现。
2. **-n/-ng 韵尾混淆**：辛纳→星纳/星达、都灵→都宁、挣来的→振来的 等，前几轮已确认的本管线固定伪影。
3. **同音选字**：兹韦列夫、穆塞蒂、黄泽林（霖）等人名的 ASR 用字出入，发音无误。

两处定向修正均在成片中得到 ASR 正面确认：S0b 结尾「先来快速看一下昨天的赛果」、S1_1 结尾「把这份悬念带进了巴黎」。

重音一项 ASR 无法判定，按项目既定口径靠句式标点构造＋试听由所有者耳判，本版不作机器断言。
