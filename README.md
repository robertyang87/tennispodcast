# tennispodcast · 网球时差播客版

网球时差的音频线：AI 辅助制作、制作+上传全流程自动化。
视频讲不完的，在这里讲透——一期 12–18 分钟，通勤和跑步时听。

## 定位

- **形式**：单人讲述 + 球员原声插入为主（每期 ≥2 处原声），辩论型选题可用双人对谈。
- **三条轮转栏目**：
  1. **赛后复盘**——当周热点比赛，蹭时效；
  2. **网球有故事·长篇版**——视频放不下的完整时间线与人物弧线；
  3. **规则与词源**——《擦网为啥喊 Let》《抢七是被逼出来的》一类已验证的互动型知识题。
- **质量线（沿用网球时差既有规矩）**：
  - 金句「不可替换」标准，至少占住标题/开场/结尾中的两处；
  - 原声优先：球员原声 ＞ 现场声 ＞ 旁白；战术判断必须写成「触发 → 动作 → 效果」并带数据锚＋时间戳锚，无锚只是印象，不许进稿当事实；
  - 旁白要懂球、有料、自然、能引发讨论，不许有明显的 AI 腔；
  - 选题先查素材库，已做过的不重报。

## 目录

- `specs/`——每期一个 episode spec（JSON），模板见 `specs/episode-template.json`
- `episodes/`——每期成品登记（标题、时长、音频 Release 链接、RSS 条目、推送回执）
- `feed/`——生成的 RSS feed（`feed.xml`），一次分发小宇宙 / Apple Podcasts / Spotify
- `docs/pipeline.md`——全自动管线设计（选题→写稿→人审→合成→质检→发布→入库）
- `tools/`——管线脚本（待建）
