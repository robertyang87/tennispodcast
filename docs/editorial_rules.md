# 文案规范（2026-11-19 所有者定）

总纲：**不啰嗦。先精准严谨，再富有感染力**——顺序不许反。感染力只能长在准确的事实、干净的逻辑和真信息量上，不靠形容词、口号和重复强调。

## 一、重复上限（结构性去重）

实测病灶（1119 期，3,726 字）：主场比赛比分「六比二、六比四」各完整出现 8 次，「锁定了小组第一」6 次，「医疗暂停」4 次——导览、新闻、过渡、话题引入、话题正文、回扣、提问，每一站都把同一组数字再报一遍。1118 期「六比二」出现 23 次、1117 期「六比三」12 次，同病。

- 同一比分/关键事实：全期**完整出现最多 2 次**——新闻段报全一次，话题段回扣一次。其余各段只许引结论（赢了/丢了/锁定/出局），不许整组数字重报。
- 导览（S0b）：只给钩子和胜负悬念，不预告完整比分。
- 过渡段（S2）：只报状态变化（谁锁定、谁出局、今天看什么），不复述比分。
- 话题段：引用新闻段已报的数据只引结论；要展开的是新角度（为什么/意味着什么/原话），不是把数字再念一遍。
- 提问段（S4a）：问题里不许再嵌完整比分。
- 删重复省出的篇幅还给新信息：背景、交手史细节、球员原话、下一场对阵与看点。总字数仍 3,600–4,000，不许靠重复凑字数。

## 二、逻辑闸（与事实闸并列，合成前必过）

1. **数字一致**：同一比分/积分/时长/连胜场次跨段逐一对齐，任何一处变值即改。
2. **顺序不倒置**：因果不倒置，先发生先说；「因为这场赢了所以锁定」类推导，前提必须在本期前文已给出。
3. **预告必兑现**：导览双钩子与 S3b 三点预告，话题段必须逐一真正回答/展开；对不上就改预告，不许挂空钩。
4. **提问须有效**：互动问题问的悬念在播出时必须尚未揭晓，且不与本期已给结论冲突（已锁定出局的人不许再问「能不能出线」）。
5. **主体不串位**：比分、胜负方、数据归属的主语逐句核对（谁的制胜分、谁的主动失误不许串）。
6. **规则断言须出处**：退赛/晋级/抢十/小组出线条件等规则类断言，必须有 news_brief 里的官方/主流出处；无出处删，不许凭印象写。

## 三、精准先于感染力

- 修辞与情绪句不许新增事实、不许夸大数字：「碾压」「横扫」类词必须有比分支撑，没有支撑就用中性动词。
- 感染力的正道：选材（最有故事性的细节）、节奏（长短句与停顿）、球员原话、具体画面。形容词堆叠和口号式排比是啰嗦，不是感染力。
- 空转句删：不传递新信息、不推进逻辑、不制造悬念的过渡句一律删，或换成具体信息。

## 四、执行

- 写稿时按本规范落；事实闸后加跑**逻辑与重复闸**：机器提取全期比分/数字表达式与关键短语的出现次数（同一完整比分出现 ≥3 次即不许过闸），六项逻辑逐项核对、留记录。
- 与既有规范的关系：本规范管「说什么、说几遍、逻辑通不通」；韵律配方 v2（docs/prosody_v2.md）管「怎么读出声」；三查管「读得对不对」。三者并行不悖。
