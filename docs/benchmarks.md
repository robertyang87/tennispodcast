# 头部网球播客声音制作标杆（2026-10-30 实测）

方法：各取最新一期前 10 分钟原音频，ffmpeg 测响度（loudnorm）与静默分布
（silencedetect -42dB/0.2s），faster-whisper base 转写核语速与开场结构。
样本：The Tennis Podcast（全球第一，TIME 百大，Athletic 旗下）、
No Challenges Remaining、Monday Match Analysis（Gill Gross 单人分析，
形态与我们最接近）、网球大排档（中文头部）、发球上网（中文，130 期）。

## 开场结构（逐秒核过）

- **TTP 没有节目自制片头**。Acast 分发的最新两期，正片前是 62–93 秒
  动态插入广告——其中 Accenture×WTA 那支是电影感品牌宣传片式配音
  （用户听到的「前导音宣传片」即此，属赞助方品牌片、非节目片头），
  之后主持人直接开说：问候 + 本周议程清单，无片头音乐。
- **NCR**：3 秒口头禅冷开场（节目名梗）直接进标题，零片头；
  先闲聊约 90 秒（嘉宾的马拉松）再进网球正题——关系感优先。
- **MMA（单人）**：0 秒问候 + 赞助口播一句 + 本周头条清单 +
  「本期只聚焦这一场」的焦点声明，然后进入分析。单人节目靠议程感立结构。
- **网球大排档**：0 秒问候 + 自嘲式自我介绍，先聊约 50 秒录制花絮再进正题。
- **发球上网**：0 秒问候，43 秒独白交代本期由来与话题清单，再切对谈录音。

## 制作规律

1. **停顿分两种形态**。对谈类：全是 0.2–0.5s 呼吸停顿（占八成），
   正文最长不超过约 1.1s。单人分析类（MMA）：19.6 次/分钟、静默 18%，
   论点转折处 regularly 出现 1.4–2.1s 的思考停顿——长留白是单人分析的工具，
   位置在论点之间，不在句子中间。
2. **语速**：英文对谈 160–220 WPM，单人分析压到 155 WPM；
   中文对谈约 230–310 字/分。我们 TTS 1.0 倍速约 300 字/分属对谈上限，
   单人讲述应回到约 240–270 字/分（MiniMax speed 约 0.85–0.9），
   v1 的「急促」更多来自全程无设计停顿 + 速率在上限，两头都要改。
3. **后期标准是「剪过的自然」**：TTP、NCR 转写里 um/uh 均为 0，
   但 you know / like 等口语连接大量保留。AI 声音的对应做法：
   稿子不写填充语气词，保留口语连接词，靠写稿达到剪辑后的自然度。
4. **响度**：精修节目锚点 -18.5 ~ -19 LUFS；NCR、MMA 的 -24 ~ -25
   是独立制作未母带，不作标准。我们发布响度定 -18 LUFS（TP -1.5）。
5. **前导位是广告位，不是片头位**（头部谈话类）。但单人品牌节目
   完全可以自制一支 10–15 秒固定前导音（标志音 + 金句原声 + 节目名）
   建立辨识度——头部谈话节目靠主持人声音本身当品牌，我们靠制作。

## 对我们参数的修正（已回写 pipeline §5）

- 停顿：正文段间 0.5–0.8s；论点转折处可 1.2–2.0s（单人分析式）；
  ≥2s 只许结尾问题后。
- 语速：叙事 0.88、钩子/金句 0.85、数据段 0.83（目标 240–270 字/分）。
- 开场：标志击球音 ≤3.5s → 人声 → 钩子或议程清单；不做长片头。
- 响度：-18 LUFS。
- 我们三版 demo 的停顿频次：v1 6.0 次/分 → v2 8.0 → v3 13.4，
  v3 已进入标杆区间（对谈 8–15、单人分析 19.6）。
