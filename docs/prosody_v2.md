# 韵律配方 v2（2026-11-19 实验定版）

实验在 ~/workspace/podcast-prosody-lab/（E1–E5），量测工具 measure.py（停顿/F0/ASR）。所有者 2026-11-19 全权授权定版。

## 通道事实（E1）

- 本地 raw-socket Edge 通道**不接受任何内嵌 SSML**：`<break>`、`<phoneme>`、嵌套 `<prosody>`、`<emphasis>` 都会让合成静默返回 0 字节。注音钉、停顿、重音都不能靠标记实现。
- 每次调用的 rate 与 pitch 有效（pitch +2st 实测 F0 中位数 124→155 Hz）；但整段 pitch 抬升不产生相对重音（E4 变体 D 否决）。

## 断句（E2）

- 引擎自身停顿语法：句号约 560–690ms、逗号约 240–390ms，另有大量 70–170ms 微停顿；逐句加逗号（呼吸组切分）对停顿结构影响很小，不作主要手段。
- **数据段弧形合并**：纯数据罗列段（如 S1 的数据小节）把逐项句号改逗号、连成 2–3 项一弧、弧尾才落句号。实测去掉约 600ms 全停顿、该段缩短 6–9%；该段 rate 相对同角色基线下调 6–9 个点补偿（实测 +16%→+7% 时长对齐：22.2s 对 21.6s），整期净语速仍以 320 锁为准复测。
- **禁止**用分段合成＋固定时长拼接冒充句间停顿（E2 变体 C 停顿机械一致约 460ms，比引擎内停顿更像机器人）。

## 多音字（E3）

- **语境救不了引擎读错的词**：「保发」在普通句与逗号隔离短句中都被读成「爆发」；唯一可靠解法是词典改写/换字（现行 rewrite_rules 与 reading_overrides 继续执行）。
- 换字注音经声学验证有效：「伯林」版 ASR 干净还原「柏林站」，直读「柏林」版被听成「百零战」。
- **一次入典规则**：任何词一旦在整句语境中被确认读错一次，立即写入 config/pronunciation.json（改写或换字），不许指望换个语境能读对。
- 验证层：全段 ASR＋孤立 medium 测试照旧；ASR 字形无法区分的声调争议（如「数」shǔ/shù）可用 F0 斜率仲裁（四声陡降、三声先降后升），只作仲裁、不作常规扫描。

## 轻重音（E4）

- 句尾关键词会被引擎的句末降调压平（实测 RMS 低于全句约 2.4–2.5 dB）。
- **写稿前置规则**：每个话题段的核心数字/结论用前置或冒号领起（「凭十一连胜：……」「十一连胜，……」式），不要把最重要的词放在长句句尾。
- **标题句可选分段合成**：本期回扣标题句（S3f 类）可把关键词子句拆出单独合成，rate −10%、pitch +1st、120ms 拼接——实测关键词时长、响度、F0 幅度均提升；每期最多用 1–2 句，多用则假。
- 整段 pitch 偏移不产生重音，禁用作重音手段。

## 不变项

净语速 320 锁、云健平叙、段间实测 1.8–2.0s、结尾问句后 ≥2.5s、−18 LUFS、原位资产强制，全部不变。
