# 默认模型与音色（暂定，盲测后修订）

机器可读版在 `config/defaults.json`，本文件记理由。

## MiniMax（声音主队）

- **默认模型：`speech-2.8-hd`**
  - MiniMax 官方的 AI 播客方案里推荐的模型就是它；
  - 播客是离线生产、质量优先，`turbo` 系列的速度优势用不上，一律不用；
  - 支持语气词标签（`(breath)` 等）、发音词典 `pronunciation_dict`（带声调拼音注音）、
    `<#x#>` 硬停顿——正对本仓最在意的三件事：多音字、断句、重音。
- **默认音色：`Chinese (Mandarin)_Gentleman`（温润男声）**
  - 官方音色目录对它的定位就是叙事/讲故事；网球时差的视频旁白一直是男声主述
    （云扬），播客延续同一听觉品牌；
  - 备选同测：`Chinese (Mandarin)_Radio_Host`（电台男主播，播报感更强，
    可能更适合「赛后复盘」栏目）；女声备选 `Chinese (Mandarin)_News_Anchor`（新闻女声）。
- **兜底模型：`speech-02-hd`**——官方定位「节奏与稳定性优先」。
  若 2.8-hd 在长句上出现韵律漂移或内容幻觉，盲测里用它同卷对照，稳者胜。
- 参数默认：speed 1.0、pitch 0、emotion 不锁死（逐段在 spec 标），
  发音词典按 spec 传入网球词库。

## OpenAI（对照组 + 脑 + 耳）

- **默认模型：`gpt-4o-mini-tts`**——三个 TTS 模型里唯一带 instructions 导演能力的，
  `tts-1` 质量低一档、`tts-1-hd` 是老一代且同样在关停名单上，都不用。
- **默认音色：`marin`**（官方推荐 marin/cedar 音质最好），`cedar` 同测对照。
- 硬伤不变：声音为英语优化、无注音手段、模型 2027-01-06 关停。
  所以它在管线里的正式角色是写稿标注与 ASR 回听，TTS 只作盲测对照组；
  万一它盲测意外胜出，也必须走可替换的引擎层接入。
